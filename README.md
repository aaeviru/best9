# PassCode Best 9

A dependency-free static song sorter for choosing a personal PassCode Best 9. It works entirely in the browser, saves unfinished progress locally, and creates a downloadable 3×3 result image plus shareable result links.

## Publish with GitHub Pages

1. Create a new GitHub repository and upload all files from this folder.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)`, then save.

GitHub will show the public URL when publishing finishes. No build command is needed.

## Preview locally

Open `index.html` directly, or serve this folder with any static web server.

## Song data

The list contains unique studio songs from PassCode's public discography through the March 2026 single “Liberator.” Instrumentals, repeated live recordings, and duplicate re-recordings are omitted.

This is an unofficial fan-made project and is not affiliated with PassCode or its labels.
